# i18n 国际化支持设计文档

**日期：** 2026-06-29  
**状态：** 已审批，待实现  
**分支：** feat/dashboard-ui-improvements

---

## 目标

为 LLM Usage Dashboard 添加多语言支持：

- 支持四种语言：简体中文（zh-CN）、繁體中文（zh-TW）、日本語（ja）、English（en）
- 通过系统托盘菜单切换语言
- 语言偏好持久化到 Tauri 本地配置文件
- 首次启动自动按系统语言选择，无初始闪烁

---

## 方案选型

**方案 C：Rust 注入初始值 + 前端实时更新**

- 启动时：Rust 读取 config.json → 注入 `window.__INITIAL_LANG__` → 前端 LangProvider 直读，无闪烁
- 切换时：托盘点击 → Rust 写文件 + `emit_all("language-changed", lang)` → 前端实时更新，无需刷新页面
- i18n 库：轻量自定义方案（零依赖），不引入 i18next 等三方库

---

## 架构

### 启动流程

```
Tauri 启动
  → 读取 ~/.config/llm-usage/config.json（无文件则 auto-detect，写入默认值）
  → window.eval("window.__INITIAL_LANG__ = '...'")
  → 构建系统托盘菜单（当前语言条目带勾选标记）
  → 前端 LangProvider 读取 __INITIAL_LANG__，初始化 LangContext
  → 注册 "language-changed" 事件监听
```

### 语言切换流程

```
用户点击托盘菜单语言项
  → Rust: 写入 config.json
  → Rust: 更新托盘菜单勾选项
  → Rust: app.emit_all("language-changed", lang)
  → 前端 LangContext: setLang(lang)
  → 所有使用 useTranslation() 的组件重新渲染
```

## 前端设计

### 目录结构

```
frontend/src/i18n/
├── locales/
│   ├── en.ts
│   ├── zh-CN.ts
│   ├── zh-TW.ts
│   └── ja.ts
├── context.tsx      # LangProvider, LangContext, useTranslation
└── index.ts         # Lang 类型, LANGS 常量, detectLang()
```

### 类型与工具（`index.ts`）

```ts
export type Lang = 'en' | 'zh-CN' | 'zh-TW' | 'ja';

export const LANGS: { value: Lang; label: string }[] = [
  { value: 'zh-CN', label: '简体中文' },
  { value: 'zh-TW', label: '繁體中文' },
  { value: 'ja',    label: '日本語' },
  { value: 'en',    label: 'English' },
];

// 从 navigator.language 推断，fallback 到 'en'
export function detectLang(): Lang { ... }
```

### LangProvider（`context.tsx`）

```tsx
export function LangProvider({ children }) {
  const [lang, setLang] = useState<Lang>(
    (window as any).__INITIAL_LANG__ ?? detectLang()
  );

  // 监听 Tauri 托盘事件，实时切换
  // 使用 useEffect 注册/注销监听器

  const t = (key: string) => translations[lang][key] ?? key;

  return (
    <LangContext.Provider value={{ lang, t }}>
      {children}
    </LangContext.Provider>
  );
}

export function useTranslation() {
  return useContext(LangContext);
}
```

> 含 `{param}` 的 key 需在 `t()` 中支持简单插值替换。

### 插值支持

`t()` 函数由 `LangProvider` 内部创建，通过 `LangContext` 提供给子组件，依赖当前 `lang` 状态：

```ts
// 在 LangProvider 内部，t() 捕获当前 lang
// t('page.info', { current: 1, total: 5 }) → "第 1 / 5 页"
const t = (key: string, params?: Record<string, string | number>) => {
  let str = translations[lang][key] ?? key;
  if (params) {
    for (const [k, v] of Object.entries(params)) {
      str = str.replace(`{${k}}`, String(v));
    }
  }
  return str;
};
```

`index.ts` 只导出 `Lang` 类型、`LANGS` 常量、`detectLang()` 函数和翻译表 `translations`，不直接导出 `t()`。

## Rust 侧设计

### 配置文件

路径：`~/.config/llm-usage/config.json`（macOS 为 `~/Library/Application Support/llm-usage/config.json`，使用 `dirs::config_dir()`）

```json
{ "language": "zh-CN" }
```

读取失败或文件不存在时，**Rust 不注入 `__INITIAL_LANG__`**，前端 `LangProvider` 将自动调用 `detectLang()` 从 `navigator.language` 推断系统语言作为初始值，并在用户首次切换时触发写入。写入时自动创建目录。无需新增 Rust 依赖（`dirs` 和 `serde_json` 已存在）。

### 新增 Tauri Command

```rust
#[tauri::command]
fn get_language() -> String {
    load_config().language
}
```

前端通常直接使用 `window.__INITIAL_LANG__`，此 command 作为兜底。

### 系统托盘

```
┌──────────────┐
│ ✓ 简体中文    │
│   繁體中文    │
│   日本語      │
│   English     │
├──────────────┤
│   退出        │
└──────────────┘
```

- 语言项 ID 直接使用 lang 代码（`"zh-CN"` 等）
- 当前语言项通过 `item.set_selected(true)` 标记勾选
- 切换时：写入 config.json → 更新菜单勾选 → `emit_all("language-changed", lang)`
- 托盘图标复用现有 `icons/32x32.png`

### `tauri.conf.json` 变更

```json
"systemTray": {
  "iconPath": "icons/32x32.png",
  "iconAsTemplate": true
}
```

在 `allowlist` 中无需额外开启（SystemTray 是 Tauri v1 内建功能）。

## 不在本次范围内

- 日期/数字格式本地化（`toLocaleDateString` 已根据系统 locale 自动处理）
- 后端错误消息的多语言（目前 error 字符串来自 Rust，保持英文）
- Web 模式（非 Tauri）下的托盘功能（Web 模式无托盘，语言默认由 `detectLang()` 决定，不可手动切换）
